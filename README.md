# 🎙 Voice Controlled Library System

A Python-based voice-controlled library management system using Speech Recognition.  
Users can perform library operations using voice commands such as adding, borrowing, returning, and viewing books.

---

## 🚀 Features

- Voice-controlled authentication system
- Add books using voice commands
- Borrow and return books
- View available library books
- Simple command-based voice interface
- Beginner-friendly AI + Python project

---

## 🛠 Technologies Used

- Python
- SpeechRecognition
- PyAudio
- Google Speech API
